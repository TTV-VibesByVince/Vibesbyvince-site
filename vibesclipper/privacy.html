VibesClipper Privacy Policy

Effective date: November 18, 2026

Who runs VibesClipper

VibesClipper is a personal tool operated by VibesByVince for his own YouTube channel only. It runs on his own computer and is not offered to anyone else.

Google and YouTube data it accesses

VibesClipper uses the YouTube Data API with these permissions:

  • youtube.upload: to upload videos to the connected YouTube channel.
  • youtube.readonly: to read the connected channel's name and ID, so the tool can show which channel is connected.

VibesClipper does not read, collect or store anyone else's data, viewers' data, comments or private account information.

How it's stored

The sign-in token Google issues is stored only on the owner's own computer (a private server at home), in a local database. It is not sent to any other service.

Sharing

Google user data is never sold, never shared with third parties, never used for advertising and never used to train AI models.

Separately, and unrelated to Google data: VibesClipper sends text transcripts of the owner's own public Twitch streams to Anthropic's Claude API to help choose clips. No Google or YouTube account data is included.

Google API Services User Data Policy

VibesClipper's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

VibesClipper uses YouTube API Services. By using it you are also agreeing to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access and deleting data

  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Disconnecting YouTube in VibesClipper deletes the stored token immediately.
  • Videos that were uploaded stay on YouTube and can be managed or deleted in YouTube Studio.
